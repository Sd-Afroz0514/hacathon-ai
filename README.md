# 🌸 SHE WIN Hackathon — SHE Twin AI Platform

Welcome to the **SHE Twin AI** project repository developed for the **SHE WIN Hackathon**.

The complete full-stack application (FastAPI backend + Vite React frontend) is located in the **[`SHE-Twin-AI/`](./SHE-Twin-AI/)** directory.

---

## ⚡ Quick Start (1-Click Run)

To immediately launch the full-stack application (Backend + Frontend + Browser):

1. Navigate into the `SHE-Twin-AI` folder:
   ```cmd
   cd SHE-Twin-AI
   ```
2. Double-click or run **[`run_project.bat`](./SHE-Twin-AI/run_project.bat)**:
   ```cmd
   .\run_project.bat
   ```

- **Frontend Application**: [http://127.0.0.1:5173/](http://127.0.0.1:5173/)
- **Backend API Docs**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
